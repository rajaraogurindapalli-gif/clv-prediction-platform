# Customer Lifetime Value Prediction Platform

**Hybrid Data Architecture with Medallion Layers, Regression Modeling, Predictive AI, and Generative AI Insights**

End-to-end portfolio project demonstrating Customer Lifetime Value (CLV) prediction using:

- Structured, Semi-Structured, and Unstructured data
- Medallion Architecture (Bronze → Silver → Gold)
- MS SQL Server + Microsoft Fabric + Power BI
- Regression-based Predictive AI
- Generative AI + RAG/Agent layer for explanations

## Business Questions
1. Predicted 12-month CLV
2. Next-quarter revenue forecast
3. Expected next order value
4. Expected support ticket volume
5. Expected satisfaction score

## Architecture
- **Bronze**: Raw data in MS SQL Server
- **Silver**: Cleaned & conformed data in Fabric
- **Gold**: Feature store for ML
- **Predictive AI**: Regression models (XGBoost/LightGBM)
- **Generative AI**: RAG/Agent for natural language explanations

## Tech Stack
- MS SQL Server
- Microsoft Fabric
- Power BI
- Python (scikit-learn, XGBoost)
- GitHub
